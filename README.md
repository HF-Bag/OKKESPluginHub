# OKKESPluginHub 插件中心

本插件由 AI 制作，完全免费分享。适用于 Windows 10/11，需要已安装完整的 **ok-kes（含内置 Python）**。

提供简繁互通、分享码导入转换、随“游戏语言”切换当前方案、人工词库校正，以及插件卡片和数据目录管理。翻译结果仍需自行核对。

## 简单使用

1. 解压压缩包，运行 `OKKESPluginHub.exe`。首次使用或更新前先退出旧版插件中心和 ok-kes。
2. 点击 **ok-kes 简繁互通** 卡片，在 **安装与路径** 中选择 ok-kes 根目录：其中应有 `ok-kes.exe` 和 `data/apps/ok-kes/python/python.exe`。这里不是游戏客户端目录。
3. 点击 **检查路径**，再点击 **安装 / 检查修复**。若发现旧版资料，先备份并按页面提示确认迁移。
4. 阅读插件内的使用说明和风险提示，**明确勾选使用确认并开启插件**，然后点击 **启动增强版 ok-kes**。以后使用增强入口启动；设置变更后请自行重启 ok-kes。
5. 在原脚本当前任务中更改 **游戏语言**，当前方案文本会随目标语言进行转换；分享码导入转换仍可用。重要方案请先备份，并检查专有名词及关键条件。

### 人工词库

在插件内部进入 **词库管理 → 导入…**，选择下载的 JSON 文件。请使用文件下载链接保存 JSON，避免将 GitHub 网页保存成文件。

搜索支持不完整词和跨简繁匹配；编辑后点击 **保存校正**。人工校正优先于自动词库，自动词库刷新不会覆盖人工校正。当前附带空文件，导入后不会增加词条。

### 数据路径与可选扫描

- **客户端设置 → 总数据目录**：管理客户端配置、图片和跟随总目录的插件资料。
- **插件卡片 → 安装与路径 → 本插件数据目录**：可单独选择插件数据位置，也可保存到总目录之外。搬迁前退出相关 ok-kes；使用 **迁移并应用**，原目录保留为备份。
- 只有同时拥有繁体与简体两个游戏客户端时，才按需启用文件扫描并分别填写两个游戏根目录；只有一个客户端也能使用内置词表和人工校正。
- 原 ok-kes 自动更新后可通过增强入口检查修复挂载；未来接口变化可能需要适配，不能保证永久兼容。
- 状态损坏时，可在插件内明确点击 **关闭 / 修复状态**，再自行确认并按需开启。

更详细说明见压缩包内 `使用说明.txt` 和插件内 **使用说明**。
